# Architecture Decision Records

ADRs explain why durable choices exist so future contributors do not remove protective complexity as an apparent cleanup.

## Status values

- **Proposed** — under review.
- **Active** — approved and authoritative.
- **Superseded** — replaced by a newer ADR; retained for history.
- **Rejected** — considered but not adopted.

## Template

```md
# ADR-NNN — Title

**Status:** Proposed | Active | Superseded | Rejected
**Date:** YYYY-MM-DD
**Decision owners:** ...
**Supersedes:** ...
**Superseded by:** ...

## Problem
## Context
## Decision
## Alternatives rejected
## Consequences
## Implementation landmarks
## Regression protection
```
